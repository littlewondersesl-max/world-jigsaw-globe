# World Jigsaw 🌍
A kids' globe puzzle: drag country pieces from the box onto a blank 3D globe, turn them to fit, and collect flag colours in the tube. Static site (d3-geo orthographic). See CREDITS.md.
Snapping: drop within a size-scaled distance of the country AND turn it within 25° of upright; it then auto-corrects. "Easy small countries" removes the turning rule and widens the target for small countries.
